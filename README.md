# Vishruth Venugobal: Personal Portfolio

**Live site:** [vishruth-v24.github.io](https://vishruth-v24.github.io)

Personal portfolio for Vishruth Venugobal, a Computer Engineering student at Purdue University specializing in **semiconductors and microelectronics**. The site is designed as a component datasheet for part "VV-2028" and covers my work in analog/RF design, hardware test and validation, software, and AI.

## Highlights

- **Interactive "decap the chip" diagram:** click to remove the package lid and reveal a die floorplan, where each functional block is one of my projects. Click a block to zoom in on its details:
  - **RF front end:** 5.8 GHz inductively degenerated common-source LNA, with an animated schematic
  - **Test & validation:** hardware test campaigns at Purdue's Rocket Propulsion Lab
  - **Compute core:** automated paper trading system (Python, Alpaca and Polygon APIs)
  - **Data / ML:** social media survey analysis (Pandas, scikit-learn, Plotly)
- **Datasheet-style layout:** Features, Applications, Description, Electrical characteristics (skills) and Ordering information (contact)
- **Responsive and accessible:** works on phones, supports keyboard navigation (Tab / Enter / Esc), and respects reduced-motion settings

## Built with

- HTML5, CSS3 and vanilla JavaScript, with no frameworks or build step
- Inline SVG for the chip, die floorplan and LNA schematic
- Google Fonts: Barlow, Barlow Condensed and JetBrains Mono
- Hosted on GitHub Pages

## Running locally

No installation is needed. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/vishruth-v24/vishruth-v24.github.io.git
cd vishruth-v24.github.io
open index.html        # macOS
start index.html       # Windows
```
